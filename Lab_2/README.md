# Лабораторная работа: TCP Эхо-чат (Client + Server)

## Задание
> **Client+Server** — выдача на сервере текстовой строки, переданной клиентом с помощью Socket (использовать протокол TCP).

---

## Структура проекта

```text
Lab_2/
├── go.mod             # Файл модуля Go
├── README.md          # Инструкция
├── server/
│   └── main.go        # TCP-сервер (~30 строк)
└── client/
    └── main.go        # TCP-клиент (~30 строк)
```

---

## Запуск в двух терминалах

1. **Терминал 1 (Сервер):**
   ```powershell
   go run ./server
   ```

2. **Терминал 2 (Клиент):**
   ```powershell
   go run ./client
   ```
   *(Также к серверу можно подключиться через команду `nc 127.0.0.1 8080`).*
